# Disclosure Boundary

## Included publicly

- sanitized system purpose;
- high-level architecture;
- engineering decisions;
- technology categories;
- validation approach;
- security and governance lessons.

## Excluded

- client identity;
- raw n8n workflow JSON;
- credentials and credential references;
- environment values;
- private endpoint configuration;
- commercial documents;
- account information;
- private conversations;
- proprietary source details.

This repository is a capability case study, not an open-source release of the client delivery.
